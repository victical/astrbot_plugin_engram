## ✨ 核心功能

### 1. 自动生成测试用例

从你导出的对话数据中，自动提取事实陈述并生成测试查询。

**示例**：
- 原始对话：`我最喜欢吃火锅`
- 生成测试：查询 `我喜欢什么`，期望召回包含 `火锅`

### 2. 自动执行召回测试

对每个测试用例：
1. 执行记忆检索
2. 检查是否召回相关内容
3. 计算相关性分数
4. 验证原文回溯是否可用
5. 记录召回耗时

### 3. 生成可视化报告

自动生成 Markdown 格式报告，包含：
- 📊 整体指标（召回率、相关性、耗时等）
- ✅ 成功案例展示
- ❌ 失败案例分析
- 💡 针对性改进建议

### 4. 支持持续监控

- 定期运行测试，追踪质量变化
- 保存历史报告，对比优化效果
- pytest 集成，可纳入 CI/CD

## 📊 评估指标

### 核心指标

| 指标 | 含义 | 优秀标准 |
|------|------|---------|
| **召回成功率** | 能否找到相关记忆 | ≥ 80% |
| **平均相关性** | 召回内容的相似度 | ≥ 0.6 |
| **平均召回耗时** | 单次检索时间 | ≤ 100ms |
| **原文回溯成功率** | 能否关联原始对话 | ≥ 80% |

### 为什么这些指标重要？

1. **召回成功率**：直接反映记忆质量
2. **相关性**：避免召回不相关的内容
3. **耗时**：影响用户体验
4. **原文回溯**：这是你的核心竞争力！

## ⚠️ 注意事项

### 1. 测试用例质量

自动生成的测试用例依赖于对话内容：
- 如果对话中缺少明确的事实陈述，测试用例会很少
- 可以手动添加自定义测试用例（见文档）

### 2. 首次运行可能较慢

- 需要加载数据库和向量库
- 首次生成测试用例需要一些时间
- 后续运行会更快

### 3. 模块导入问题

如果遇到导入错误：
1. 确保在项目根目录运行
2. 检查 Python 环境和依赖
3. 参考文档的常见问题部分
